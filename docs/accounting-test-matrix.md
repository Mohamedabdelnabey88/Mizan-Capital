# مصفوفة حصر وظائف ميزان كابيتال للاختبار المحاسبي

## معيار القبول العام لكل عملية مالية
1. حفظ سجل تشغيلي واحد مرتبط بالقيد أو القيود الصحيحة، مع منع التكرار عند إعادة الطلب.
2. توازن إجمالي المدين والدائن بالهللة، وعدم السماح بحساب غير معروف أو مشروع/تاريخ غير صالح.
3. مطابقة أثر العملية على النقدية والبنك والالتزام/الأصل/حقوق الملكية مع دفتر الأستاذ.
4. عدم تسجيل التمويل أو سداد أصل الدين أو رد سلفة المالك كإيراد أو مصروف تشغيلي.
5. تحديث الملخصات والبطاقات والتقارير بعد الحفظ، واستخدام نفس نطاق المشروع والفترة بوضوح.
6. رفض تجاوز الرصيد المتاح أو الالتزام المتبقي، ورفض التواريخ غير المسموحة دون إنشاء سجل أو قيد جزئي.
7. عند الإلغاء/العكس، الاحتفاظ بأثر المراجعة وإنشاء قيد عكسي متوازن بدل حذف التاريخ المالي.

## حصر الوظائف التي سنختبرها

| القسم | العمليات والوظائف | ما يجب مطابقته في الصفحات الأخرى |
|---|---|---|
| 1. نظرة عامة | أرصدة النقد والبنك، الربح، الالتزامات، السلف، التحذيرات | دفتر الأستاذ، التقارير، الالتزامات، والسيولة المتوقعة |
| 2. رأس المال والتمويل | الأرصدة الافتتاحية، رأس المال، التمويل العام، تخصيص التمويل | النقد والبنك، حقوق الملكية/الديون، مصادر التمويل، الميزانية |
| 3. المشاريع والاستثمارات | إنشاء المشروع، تكاليفه، الأصول، دورة الاستثمار وعائدها | بطاقة المشروع، السيولة، الأرباح، الاستثمارات والتقارير |
| 4. عقود المشاريع | إنشاء العقد، الأقساط، التحصيل، السداد، الإلغاء والتعديل | تقويم الالتزامات، الحركات، الإيراد/المصروف، سجل المراجعة |
| 5. التقارير اليومية | تسجيل التقرير، قنوات التحصيل، الاعتماد والتصحيح | أرصدة النقد/البنك، مستحقات البطاقات، الإيرادات، الربح |
| 6. الحركات | إيراد، مصروف، تحويل بين الحسابات/المشاريع، عكس قيد | دفتر الأستاذ، النقد، الربح، التدفق النقدي، ميزان المراجعة |
| 7. السيولة المتوقعة | المقبوضات والمدفوعات المتوقعة، سيناريوهات التأخير والصدمات | الأرصدة الفعلية منفصلة عن التوقعات، تقويم الالتزامات |
| 8. تقويم الالتزامات | إنشاء استحقاق، تكراره، دفعه/تحصيله، تأجيله أو إلغاؤه | الالتزامات، النقد، القروض، الإيجارات، الرواتب والحركات |
| 9. التزاماتي | الموردون، الإيجارات، الضرائب، السلف، التحصيلات | دفتر الأستاذ، بطاقات الالتزامات، السيولة، التقارير |
| 10. التمويل والقروض | إنشاء قرض، جدول السداد، أصل الدين والفائدة، السداد المبكر | رصيد القرض، النقد، مصروف الفائدة، التدفق النقدي |
| 11. قروض شخصية | تسجيل القرض/السداد وتصنيف الاستخدامات الشخصية | الحساب الشخصي/التوزيعات منفصلة عن مصروف المشروع وربحه |
| 12. الموظفون والرواتب | ملف الموظف، جدولة الراتب، الاستحقاق، الصرف والتعديل | التزامات الرواتب، النقد/البنك، سجل الموظف، التقارير |
| 13. إدارة المخاطر | تسجيل الخطر، تقدير الاحتمال/الأثر، خطة المعالجة والإغلاق | مركز القرار والتنبيهات؛ لا يُنشأ قيد مالي دون عملية مالية فعلية |
| 14. مركز القرار | ترتيب المشاريع والمؤشرات والإنذارات | مصدر كل رقم هو نفس قيود وتقارير الفترة والنطاق المختارين |
| 15. التقارير المحاسبية | قائمة الدخل، الميزانية، ميزان المراجعة، التدفق النقدي، التصدير | مطابقة دفتر الأستاذ والبطاقات وعدم إدخال الخطط ضمن النتائج الفعلية |
| 16. الضبط وسجل المراجعة | السنة المالية، الفترة المختارة، السياسات، الإقفال، سجل التغييرات | تطبيق التاريخ الفعلي للسياسة، منع التعديل غير المسموح، حفظ الأثر التدقيقي |

## اختبارات انحدار ذات أولوية عالية

### رد سلفة المالك
- زر لوحة النظرة العامة يفتح اختيار السلفة مباشرة، ولا يحوّل المستخدم إلى صفحة الالتزامات.
- يعرض الاختيار كل سلفة مفتوحة ومبلغها المتبقي، بما فيها السلف العامة عند اختيار مشروع محدد.
- يفتح الاختيار نموذج الرد مع السلفة المحددة والمبلغ المتبقي مُسبق التعبئة؛ يمكن رد جزء أو كامل المتبقي.
- عند اعتماد الرد: ينخفض النقد/البنك والالتزام للمالك بالمبلغ نفسه، ويظل الربح دون تغيير.
- يرفض الرد الأكبر من المتبقي، أو التاريخ السابق للسلفة، أو عدم كفاية الرصيد، من دون سجل/قيد إضافي.
- يعاد تحميل بيانات مساحة العمل بعد النجاح وتنعكس النتيجة في البطاقة والجدول والتقارير.

### المطابقات الحسابية الشاملة
- كل قيد متوازن: مجموع المدين = مجموع الدائن.
- النقد والبنك في التدفق النقدي الختامي يطابقان حسابات النقد والبنك في دفتر الأستاذ.
- الأصول = الالتزامات + حقوق الملكية + نتيجة الفترة، مع فرق ميزانية يساوي صفرًا.
- أصل القرض سداد تمويلي وليس مصروفًا؛ الفائدة مصروف؛ التمويل الوارد ليس إيرادًا.
- الخطط والتوقعات لا تغيّر الربح الفعلي أو أرصدة الدفتر.
- التحويل بين المشاريع لا ينشئ ربحًا، وتبقى قيود كل مشروع والورشة الكاملة متوازنة.
- التصحيح والعكس لا يمحوان التاريخ؛ ينشئان قيودًا مقابلة مع أثر مراجعة.
- عند تغيير النطاق/الفترة، تُعرض السلف العامة كالتزامات عامة ولا تُحمّل على مشروع منفرد، مع بقاء إجمالي مساحة العمل متسقًا.

## حالات الاختبار التي يجب تسجيل نتيجتها
لكل وظيفة نسجل: **نجح/فشل**، المدخلات، رقم السجل، رقم القيد، المدين والدائن، رصيد ما قبل/بعد، الصفحات المتأثرة، ورسالة الرفض المتوقعة عند الاختبار السلبي. لا تُستخدم بيانات الإنتاج لاختبارات الإتلاف أو العكس؛ تنفذ الحالات التدميرية في بيئة اختبار فقط.
